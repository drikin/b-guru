# Mac: スリープさせない（keep awake）

2026-10-26 オーナー「https://github.com/vorssaint/vorssaint-utils のスリープ防止機能を取り込みたい」。全員に出す。

## 前提
- vorssaint-utils は GPL-3.0。**コードは写さない**（B-guru の Mac 版は GPL ではない）。機能の考え方だけ参考にし、macOS の公開 API で一から書く。
- 使うのは `IOPMAssertionCreateWithName`（`PreventUserIdleSystemSleep`、画面も消さないときは `PreventUserIdleDisplaySleep`）と、電池は `IOPSCopyPowerSourcesInfo`。サンドボックスのまま、追加の許可なし。
- 入れないもの: ふたを閉じても動かし続ける（管理者パスワードと `pmset disablesleep` の sudo ルールが要る。安全のため）、ポインタを動かす（アクセシビリティの許可が要り、上で足りる）。
- 防ぐのは「放っておいたときのスリープ」だけ。ふたを閉じる・スリープを選ぶ・電源ボタンでは普通に眠る。

## 使い方
- ビーグルの右クリックのメニューに「☕ スリープさせない」（下に: 切るまで／30 分／1 時間／2 時間／4 時間／—／画面も消さない ✓／止める）。⋯ の設定にも同じ節。
- 入っているあいだはビーグルで分かる（小さな印。ツールチップ・アクセシビリティの説明に「スリープさせない（〜時まで／切るまで）」）。
- 時間が来たら止めて、知らせを 1 回（「スリープさせない を終えました」）。
- アプリを終了したら必ず止める（assertion を外す）。

## 自動
- 🍻・ボイスルーム・部室の音声に入っているあいだ、📺 を再生しているあいだ（**既定オン**）。
- 選んだアプリが動いているあいだ（既定オフ。動いているアプリから選ぶ）。
- 電源につながっているあいだ（既定オフ）。
- 外部ディスプレイがあるあいだ（既定オフ）。
- 手動と自動のどれかが当てはまれば入る。理由はツールチップに出す（「🍻 の音声」「Xcode が動いている」など）。

## 電池
- 電源につながっていなくて、残りが設定の値（既定 20%）以下になったら、手動・自動とも止めて知らせを 1 回（「電池が少ないので、普通のスリープに戻しました」）。電源につながるか、残りが値より 5% 以上戻るまでは入れない。
- 電池の無い Mac（デスクトップ）では何もしない。

## 記録
- 設定は手元だけ（UserDefaults）。サーバへは何も送らない。

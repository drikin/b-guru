# ネタ帳を B-guru に取り込む — 方針と段取り（2026-11-13）

ドリキンの要望: ネタ帳（https://neta.backspace.fm）を B-guru に統合する。Bluesky ログインをやめ、backspace.fm（Ghost）に登録した人なら有料・無料を問わず使えるようにする。BSM 有料会員への入り口にもする。

## 決まったこと（オーナー 2026-11-13）

- **B-guru に取り込む**（ネタ帳を単体で残してログインだけ替える案は採らない）。
- **「聞きたい」は無料登録（メールだけ）が必須**。1 人 1 票。読むだけなら誰でも。
- **参加は全部無料**。投稿・聞きたい・コメントは無料会員もできる。有料会員は「一緒に聞いて話す場所」が特典。
- 本番ネタ帳の認証なしの `POST /api/debug/clear-stars` は「あとで」（今は触らない）。

## 作りの要点

### 本人確認と立場（一番大事）
- B-guru は「セッションがある＝有料会員」を前提にしている（`getSessionEmail` を使うファイルが 86）。無料会員に普通のセッションを出すと、それが全部開く。
- `sessions` に `tier TEXT NOT NULL DEFAULT 'paid'` を足し、`getSessionEmail()` は `tier = 'paid'` だけ返す。これで既存の機能は全部、何もしなくても有料会員だけのまま。
- ネタ帳だけ新しい `getViewer()`（email と tier を返す）を使う。
- 無料会員は `users` / `user_profiles` に入れない（補完や一覧に混ざらないように）。`neta_members(ghost_member_id, email, display_name)` に分ける。
- 無料の tier にはアプリの鍵（agent token）を出さない。アプリは今までどおり有料会員だけ（App Store の審査のことも考えて）。
- ログイン: 今のメールのコードとリンクをそのまま使い、Ghost の free も通す入口を、ネタ帳から入ったときだけ使う。Ghost にいない人は、その場で無料会員を作る（ニュースレターは既定でオフ、label でネタ帳からの登録と分かるように）。

### データ
- B-guru の Postgres に `neta_weeks / neta_topics / neta_votes / neta_comments / neta_scripts`（Netaspace の `users`・`sessions` とぶつかるので接頭辞は必須）。
- 1 人 1 票は `UNIQUE(topic_id, voter_key)` で DB が守る。fingerprint は捨てる。
- 移行: weeks と topics はそのまま。昔の「聞きたい」は人に紐付いていないので `legacy_star_count` として凍結し、表示は「昔の票＋新しい票」。昔のコメントは自由入力の名前のまま。

### 画面と URL
- `bsm.backspace.fm/neta`（今週）、`/neta/w/<週>`、`/neta/t/<話題>`。ログインなしで読めるサーバ描画のページ＋OGP。
- `neta.backspace.fm/*` は 301 で転送する。ただし POST `/api/topics`（Chrome 拡張・ブックマークレット）は 301 で送れないので、互換の受け口を残す。
- 有料会員: メニューに「📝 ネタ帳」。無料会員: 同じ `/neta` を、会員限定のメニューを出さない細い作りで。会員限定の画面に来たら説明ページ。
- 未ログインで「聞きたい」を押す → 下からシートでメール → コード → 戻ると 1 票入っている。
- 会員の総数・登録者数はどこにも出さない。B-guru の投稿の文は公開ページに出さない。

### 有料への入り口（押し付けない）
1. 自分のネタが番組で取り上げられたらメール（末尾に 1 行だけ B-guru の案内）。
2. ライブ収録の日: 有料会員には B-guru のチャットと部室で一緒に聞く入口。
3. 話題のページに「B-guru でこの話題を話す」（有料はタイムラインへ。無料には中身も件数も出さない小さなカードだけ）。
4. 🐶 ビーグルの話題まとめ（有料だけ）。
5. 毎週のまとめメール（本人が選んだ人だけ）。
- 入れないもの: 有料会員の票を重くする、投票の途中で課金画面、「残り◯票」で急かす。

### 守ること
- 投稿・コメント・聞きたいに、会員単位と IP 単位のレート制限（B-guru の `hitLimit`、nginx の後ろなので IP は X-Forwarded-For）。
- 無料登録は誰でもできるので、ログインメールの回数制限がスパム対策の最前線。新しい人の投稿は承認待ちにできるように。
- 公開ページの名前は、本人がネタ帳で決めた表示名だけ。

# Mac: ビーグルで電池の残量を見せる

2026-10-26 オーナー「バッテリーの残量がビーグルアイコンで細かく確認できるようにしたい」。選択: 「ビーグルの体が満ちる」「設定でオンにしたとき」。全員に出す。

- ⋯ の設定（と右クリックのメニュー）に「🔋 ビーグルで電池の残量を見せる」。**既定はオフ**。電池の無い Mac では項目を出さない。
- オンのあいだ、ビーグルの体の塗りが残量ぶん（下から満ちる。100% で全部、0% で輪郭だけ）。テンプレート画像のまま（ライト／ダーク両方）。
- 充電中は小さな ⚡ の印、20% 以下（または macOS の低電力の目安）はしょんぼりの姿勢（耳が下がる等、今の絵の範囲で）。
- 細かい値はマウスを乗せたとき（ツールチップ・アクセシビリティの説明）と右クリックのメニューの先頭の行: 「🔋 82%・残り 4:10」「⚡ 充電中 82%・満充電まで 0:40」「電源につながっています 100%」。値は IOPS（`IOPSCopyPowerSourcesInfo` の Current Capacity / Max Capacity / Time to Empty / Time to Full Charge / Is Charging / Power Source State）。
- 今の「体が塗られている＝新着」の意味は、オンのあいだは使わない（新着はビーグルの横の件数と「@」で分かる）。オフに戻せば今までどおり。
- 走る・吠える・カップの印（☕ スリープさせない）とは重ねても崩れないこと。
- 電池の変化は IOPS の通知で受ける（定期的に起きない）。表示の更新は 1% 変わったとき・充電の状態が変わったときだけ。
- 何も外へ送らない。

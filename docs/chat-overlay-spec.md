# チャットの上に機能を重ねる形 — 仕様（v1, 2026-10-25）

チャット欄の 2 段目（テキスト｜ルーム｜☗｜🎮｜🍻 ＋ 📺）が煩雑になり、iPhone では幅を超えてはみ出した。
チーム検討（Claude Reports「B-guru チャット欄の整理」2026-10-25）とモック（Artifact「B-guru チャットの重ねる機能」）を経て、
オーナー（drikin）が「これ実装してみてみんなのフィードバックもらいましょう」と決めた。

## 決めたこと

- **2 段目はスイッチだけ**: 🏠部室🎧n ・ ☗ ・ 🎮 ・ 📺 ・ 🍻（その人に出ている機能だけ）。「テキスト」の段はなくす
  （チャットのログはいつも見えている）。押すとその機能がチャットの上に重なって出る、もう一度押すと消える。
  入っているスイッチは色付き（緑の枠と薄い緑の地）。
- **● は「今動いている」だけ**: ☗ 対局中・🍻 開催中・📺 再生中・🏠 誰かが話している。未読は数字の赤丸（✉️ だけ）。
  4 プラットフォームで同じ印（オレンジの小さな点）。
- **チャットはいつも画面いっぱい**: 機能の面はレイアウトを押し下げず、チャットのログの上に重なる。
- **小さな窓（mini）**: スイッチを入れると、その機能が小さな窓でチャットの上に重なる。いくつでも出せる。
  ドラッグで動かせる（画面の中に収める）。位置は端末に覚える。
  - 📺: 小さな動画（今の浮かぶ窓）
  - 🍻: 題・話している人・🎧人数・「🔊 聞く」・📷
  - ☗: 小さな盤（または「対局中 6 手・あなたの番」）
  - 🏠: 部室で話している人の顔と「入る／出る」・マイク
  - 🎮: mini は「今日のベスト」だけ。押すと広がる
- **広げる（expanded）**: 小さな窓をタップ（⤢）すると、その 1 つだけがチャットの上半分（iPhone は高さの約 50%、
  Mac・Web は窓の大きさ）に広がる。☗ を指す・🍻 の写真を見る・部室を歩くはここで。**広がるのは同時に 1 つ**:
  ほかの窓は「📺 再生中」「🍻 mazzo 話し中」のような**丸い札**に縮み、札をタップすると入れ替わる。
  ⤡ で小さく戻す。🎮 はスイッチを入れると最初から広げた状態で開く（大きくないと遊べない）。
- **入力中**: 入力欄にフォーカスが入ったら、重ねた窓はすべて 2 段目のスイッチの横の札に縮む（声・動画は止めない）。
  入力が終わる（フォーカスが外れる・送る）と元に戻る。
- **音は今の決まりのまま**: 🍻 を聞く・ボイス／部室・📺 の音の排他は今の各 store のとおり（2 つの部屋の声を同時に出さない）。
  スイッチを切っても、聞いている音は止めない（📺・🍻 の音を止めるのはそれぞれの「止める」）。※ スイッチを切ると
  窓は消えるが、音が続いているものは札として残る。
- **Web**: 同じ考え方。広い画面ではスイッチに名前も出す（🏠 部室・☗ 将棋・🎮 ゲーム・📺 みんなで見る・🍻 オフ会）。
  窓はチャット欄の中で動かせる。
- **Mac**: パネルの上部のアイコン列をスイッチにし、窓はチャットの上に重ねる（パネルが狭いので広げると全体を覆う）。
- **切り替え**: サーバの `CHAT_OVERLAY_ENABLED`（featureEnabledFor、メールのカンマ区切り／"1"）。アプリは capabilities の
  `chat_overlay.enabled`、Web は `/api/auth/me` の `chatOverlay`。**false のときは今までの段のまま**（アプリを出し直さずに戻せる）。
  公開は全員（フィードバックを集める）。

## 作り（各プラットフォーム）

- 機能の一覧は 1 か所の登録表に: `Activity { id, icon, label, isAvailable, isLive, liveText, mini, expanded }`。
  2 段目・小さな窓・札・広げた面はこの表を描くだけにする（次に機能を足すときに 1 か所で済むように）。
- 状態は 1 か所（`ActivityHub` / `OverlayModel`）: どれが出ているか（集合）、どれが広がっているか（1 つ以下）、各窓の位置、
  入力中か。各機能の store の `open` とつなぐ（新しい形のときは store の open を「スイッチが入っている」と同じ意味に使う）。
- 外から開く道（push・リンク・デモ）は、新しい形では「スイッチを入れて広げる」にする。
- 今までの形のコードは消さない（切り替えで戻すため）。

## 確かめること

- 全機能オン・一番狭い画面（iPhone SE 幅 320pt 相当 / Android 360dp）・一番大きい文字で、2 段目が画面幅を超えない
  （超えるなら 2 段目だけ横にスクロール）。
- 入力中に窓が縮み、送ると戻る。キーボードが窓に隠れない。
- 🍻 の聞く・📺 の再生がスイッチの出し入れで止まらない。
